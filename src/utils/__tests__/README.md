# Tests

This directory contains unit tests for utility functions.

## Running Tests

```bash
# Run all tests
npm test

# Run tests in watch mode
npm run test:watch

# Run tests with coverage
npm run test:coverage
```

## Test Files

- `songParser.test.ts` - Tests for song parsing utility
- `playlist.test.ts` - Tests for playlist parsing utility
- `timestamp.test.ts` - Tests for timestamp formatting utility
